# สถานีพีรภัทร – PeephatZ Studio

เว็บสตรีมมิ่งเพลงและวิดีโอของ PeephatZ Studio

## Deploy บน GitHub Pages

1. สร้าง repo ใหม่ที่ [github.com/new](https://github.com/new) (ตั้งชื่อเช่น `peephatz-station` หรือ `19feb`)
2. **อย่า** เลือก "Add a README" (เรามีอยู่แล้ว)
3. ในโฟลเดอร์โปรเจกต์รัน:

```bash
cd c:\Users\pp_ou\Documents\19feb
git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPO_NAME.git
git branch -M main
git push -u origin main
```

4. เปิด GitHub repo → **Settings** → **Pages** → Source เลือก **main** → Save  
5. หน้าเว็บจะอยู่ที่ `https://YOUR_USERNAME.github.io/YOUR_REPO_NAME/`
